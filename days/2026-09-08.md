  A browser-only tool that runs ffmpeg through WebAssembly and re-encodes one input into five H.264 variants side by side, so you can pick the smallest file that still looks acceptable. - **find_secrets.py, an entropy scanner for leaked credentials** (github, 2026-09-06) [link](https://github.com/simonw/tools/commit/a9e50ebeef3e35f504d77256cc7294e591f548a4)
  A dependency-free Python script (PEP 723 inline metadata, Python 3.10+) that flags likely secrets in a local file, an HTTP(S) URL, or stdin. It uses two detection paths. The first is a prefix regex for known token shapes — `sk-`, `sk-proj-`, `sk-ant-`, `ghp_`/`gho_`/`ghu_`/`ghs_`/`ghr_`, `github_pat_`, `xox[baprs]-`, `AIza`, `AKIA`, `ASIA`, `sk_live_`, `rk_live_` followed by twelve or more characters. The second is a Shannon-entropy fallback that reports any token of 20+ characters scoring at least 4.0 bits per character, with a separate 3.0 threshold for pure hex strings because hex caps out at four bits per character. Matches print bracketed with 15 characters of context on each side.

  The docstrings are unusually candid about the limits: entropy is "not a validity check", the help text warns that results "can include hashes and miss secrets", and the fetcher is scoped to read only the resource you name — it does not follow links or try the secrets it finds against any service.

- **Animated morph between Mercator and Equal Earth** (github, 2026-09-07) [link](https://github.com/simonw/tools/commit/a1af96fb9224baa664b67a8117a25c61b60b8508)
  A 373-line single-page D3 map that blends the two projections continuously rather than cutting between them. It calls `d3.geoMercatorRaw` and `d3.geoEqualEarthRaw` for each point and interpolates the two results against a slider running 0 to 1000, so the transition is computed per coordinate instead of being a crossfade between two rendered maps. Mercator's latitude is clamped before projection to keep the poles finite, and the frame is sized from `geoEqualEarthRaw` evaluated at (π, 0) and (0, π/2). There is a 15° graticule toggle, and the slider exposes an `aria-valuetext` label as it moves.

  Built the same morning as the video compressor but with a different model: the commit links a GPT-6-Astra Medium share from ChatGPT, where the video tool came from Claude Fable 5.1. ## Mitchell Hashimoto
- **Ghostty: never stop the display link while holding the draw mutex** (github, 2026-09-07) [link](https://github.com/ghostty-org/ghostty/commit/82232ecde55405559dec29c5466cb9e39938cb41)
  A macOS deadlock fix, closing issue #14150. His own description of the mechanism: `drawFrame` called `syncDisplayLink` from its no-redraw path while still holding `draw_mutex`, and `syncDisplayLink` stops the `CVDisplayLink` when there is no work left. `CVDisplayLinkStop` is a blocking join on CoreVideo's IO thread. Because the macOS apprt also calls `drawFrame` from the CoreAnimation layer display callback on the main thread, taking that same mutex, any stall inside CoreVideo during the stop deadlocked the two threads against each other. The fix keeps the display-link stop out from under the mutex.

  Worth knowing where this actually lands: Ghostty's newest tag is still v1.3.1 from 13 March 2026, so this is main-branch work that reaches users through the nightly build rather than a release. It was also the only substantive commit he merged in the window — the rest were dependabot action bumps, a fontconfig update to 2.18.3, and an iTerm2 colour-scheme sync.
