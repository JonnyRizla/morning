- **Ghostty's bash integration was reporting every command as exit 0** (github, 2026-09-16) [link](https://github.com/ghostty-org/ghostty/commit/8482d5454e0eee8329cadf2711be78c40298b6ec)
  The Bash 4.4+ hook already captured `$?` and passed it to `__ghostty_precmd`, which ignored the argument and read its own invocation status instead — so the OSC 133;D command-end marker always carried zero, and anything downstream keying off command success saw none. The fix is `local ret="${1:-$?}"`, plus a `__ghostty_status` variable consumed and unset in `__ghostty_hook`. Jon Parise's three commits, merged as PR #14250, fix #14247.

  The subtler half is scalar `PROMPT_COMMAND`. Bash 5.1+ restores the status for each array entry, but a scalar's existing commands run first and clobber it, so Ghostty now prepends `__ghostty_status=$?` and a `__ghostty_restore_status` helper (falling back to `(exit "$n")` in subshells that inherit the string without the function) before whatever was already there. A separate one-character fix — `"declare -a "*` to `"declare -a"*` — means array `PROMPT_COMMAND`s declared with extra attributes are now detected as arrays instead of being appended to as strings.

- **Ghostty finishes the `cImport` removal: zero uses left across 50 files** (github, 2026-09-16) [link](https://github.com/ghostty-org/ghostty/commit/8fff9d6e98ccb37930629429dafdb02ff97faaea)
