- **Datasette ships about twenty security fixes across 1.0a39 and a 0.65.4 backport** (github, 2026-09-10) [link](https://github.com/simonw/datasette/blob/1.0a39/docs/changelog.rst)
  Both tagged within four minutes of each other on 10 September and on PyPI just after midnight UTC. The theme is permission checks that could be walked around by naming a resource differently: table and view permissions now honour SQLite's case-insensitive name matching; viewing a full-text search index table checks permission on the table it draws from; `sqlite_stat1` through `sqlite_stat4` are denied by a default hook; `?_through=` filters require permission on the intermediate table; and row endpoints check permission *before* resolving primary keys, so a 404 no longer reveals that an invisible primary key exists.   The non-security change worth knowing: `db.execute_write()` now has a default 2,000ms execution limit, independent of `sql_time_limit_ms`, which plugins override with `time_limit_ms=` or disable with `None`. The changelog points at a datasette.io post for the full write-up; that host is unreachable from here, so this is from the changelog at the tag.

- **A one-node WirePlumber rule to stop a KEF speaker's USB firmware from wedging** (github, 2026-09-11) [link](https://github.com/basecamp/omarchy/commit/31bd80daa4613ffdee995ac27467fce5a2990806)
  The commit message is a full fault write-up. WirePlumber suspends an idle sink after five seconds; the KEF LSX II LT's USB firmware then stops answering control requests, and the kernel logs `usb_set_interface failed (-110)`, `clock source 1 is not valid` and `cannot set freq 48000 err -110`. PipeWire cannot bring the sink back and only a physical replug recovers it — on one machine this hit "six days over three weeks, up to hundreds of timeouts a day". The fix is nineteen lines of `monitor.alsa.rules` matching `~alsa_output.usb-KEF_LSX_II_LT.*` and setting `session.suspend-timeout-seconds = 0` for that node alone, so every other sink keeps the default idle suspend.

  A nine-line migration seeds the config for existing installs and runs `systemctl --user try-restart wireplumber.service`, because `conf.d` is only read at startup. 28 added lines, no deletions, co-authored-by Claude Fable 5.1.
